Top 8 Viva Questions & Model Answers for CNIP Defense

Q1: How does Dijkstra's algorithm work in this project?

Answer: Dijkstra's algorithm is a greedy single-source shortest path algorithm. It maintains a tentative distance array initialized to infinity (0 for source) and a visited set. In each step, it picks the unvisited intersection with the minimum tentative distance, marks it visited, and relaxes all adjacent links. It runs in $O(V^2)$ with an adjacency matrix or $O((V+E)\log V)$ with a min-heap.

Q2: What is Distance Vector Routing and the Bellman-Ford equation?

Answer: Distance Vector Routing is a distributed algorithm where each traffic router node periodically shares its routing table vector with direct physical neighbors. Paths are calculated using $D_x(y) = \min_v \{ c(x, v) + D_v(y) \}$, where $c(x,v)$ is the link cost from $x$ to neighbor $v$, and $D_v(y)$ is $v$'s cost to reach $y$.

Q3: How does the Leaky Bucket algorithm prevent network congestion?

Answer: The Leaky Bucket turns a bursty, unpredictable packet stream into a smoothed Constant Bit Rate (CBR) stream. Incoming packets are enqueued into a finite buffer (the bucket). Packets leak out at a fixed rate $R$. If packets arrive when the bucket is full, they are dropped. This prevents router buffers in the city backbone from collapsing.

Q4: What is the difference between TCP and UDP in this traffic network?

Answer: UDP (User Datagram Protocol) is connectionless, fast, and lightweight with no acknowledgment overhead, making it ideal for high-volume vehicle telemetry sensor feeds where occasional packet loss is tolerable. TCP (Transmission Control Protocol) is connection-oriented and reliable with three-way handshaking, retransmissions, and congestion control, used for critical emergency signals and traffic light state synchronization.

Q5: How do we calculate Packet Loss Rate, Throughput, and PDR in NS-2?

Answer: Using AWK scripts on the .tr trace file:
• Packet Loss Rate = $(\text{Dropped Packets } 'd' / \text{Enqueued Packets } '+') \times 100$
• Throughput = $(\text{Received Bytes } 'r' \times 8) / (\text{Duration} \times 1000) \text{ kbps}$
• Packet Delivery Ratio (PDR) = $(\text{Received Packets } 'r' / \text{Sent Packets } '+') \times 100$.

Q6: What causes network congestion collapse under extreme traffic?

Answer: When arrival rate exceeds channel transmission capacity, packets accumulate in router buffers. Once the buffer hits capacity, subsequent packets are dropped (DropTail). Retransmissions by transport protocols like TCP further exacerbate the queue buildup, causing throughput to plummet while latency spikes exponentially.
